# Support
InterruptLab is a GitHub source preview, candidate version 0.1.0. No production support, response SLA,
continuous availability or enterprise service is promised.
Use the configured GitHub repository's issues for ordinary bugs and feature proposals
when that repository is available. Include version, OS, Node version and a minimal
synthetic reproduction. Do not post secrets, private traces or security details.
Private security reporting is enabled through GitHub; see SECURITY.md.
No private conduct-reporting channel is offered for this preview. No email reports are
requested. See CODE_OF_CONDUCT.md.

Linux / Node 22.22.3 is locally tested. macOS is a CI target, not locally verified.
Windows is untested. Only cooperative in-process JavaScript/TypeScript drivers are
supported. CLI workers provide a watchdog, not a security sandbox. See docs/limitations.md.
