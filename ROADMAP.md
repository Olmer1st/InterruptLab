# Roadmap
## Implemented locally
- R1: strict TypeScript/ESM workspace scaffold, smoke tests and synthetic resume proof.
- R2: reusable driver/context API, four deterministic boundaries, cancellation event
  lifecycle, bounded deadlines, fresh-context resume and JSONL recorder.
- R3: SQLite/memory effect oracles, transactional calls, six invariant families,
  repeated buggy/fixed and incomplete-observation controls.
- R4: strict YAML/JSON scenarios, init/run/demo/report CLI, four report formats,
  conservative outcomes, path/size restrictions and source/consumer examples.
- R5: child watchdogs, privacy checks, output collision prevention, clean consumer
  packaging/type smoke, release documentation and scoped secret/license review.

## GitHub preview follow-up
- Keep the enabled GitHub private vulnerability reporting route documented and usable.
- Private conduct reporting is deferred; no email reporting channel is planned.
- Run hosted CI on Linux and macOS; macOS remains untested locally.
- Obtain two unfamiliar-developer integration trials; no pilot results are claimed.
- Re-run the release checklist before a supported versioned release. npm publication
  remains deferred for a separate maintainer decision.

## After v0.1, if useful
- Framework adapters (LangGraph JS / MCP) with honest observation limits.
- Parallel branch barriers and optional HTML timeline.
- Broader platform/runtime support and stronger independent secret scanning.

Milestone completion is separate from public release readiness. See
[release readiness](docs/release-readiness.md) for remaining checks and
[development plan](docs/DEVELOPMENT_PLAN.md) for the acceptance gates.
